# K typer

Jeu de bestiaire solo en HTML, CSS et JavaScript natifs : tapez les mots qui apparaissent pour gagner de l'Essence (combos, mots dorés), invoquez des créatures qui produisent en continu, fusionnez-les pour découvrir les 23 espèces, achetez des améliorations et suivez les objectifs. Aucun outil ni dépendance n'est requis : ouvrez `index.html` dans un navigateur pour jouer.

Pour publier sur GitHub Pages, activez Pages sur la branche et le dossier qui contiennent `index.html`. Les chemins relatifs permettent également une publication depuis un sous-chemin de dépôt.

La progression est sauvegardée dans le stockage local du navigateur. La récupération hors ligne est plafonnée à huit heures ; les données de jeu restent sur l'appareil.
